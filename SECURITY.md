# Security Policy

## Supported versions
Only the latest release receives fixes.

## Reporting a vulnerability
Please do **not** open a public issue for security problems.
Use GitHub's **Security → Report a vulnerability** form on this repository, and include:
- what the problem is and how to reproduce it,
- the app version (Settings → About) and your iOS version.

## Known limitations
- iOS 5.x lacks modern TLS and system security updates. Treat the device as less secure than a current one.
- The app is unsigned and needs a jailbroken device, which weakens iOS protections.
- Do not use TelegraPh for sensitive conversations on a device you do not control.
